# DevPilot

聚合开发、费用、安全与技能数据的个人开发助手。

## 能做什么 / What it does
- 汇总 CodeGraph、TokenTrack、ChangeGuard 数据
- 展示代码库、AI 费用与安全状态
- 检查未扫描、费用超标等环境问题

## 快速使用 / Quick Start
```bash
python3 devpilot.py dashboard
python3 devpilot.py check
```

## 示例输出 / Example Output
```text
🏠 DevPilot Dashboard
代码｜费用｜安全｜技能
```

## 技术栈 / Tech
- Python 3.9+，JSON

## 适用场景 / Use Cases
- 每日开发概览、工具链健康检查
